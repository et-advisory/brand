# Logos

The proposed ETA logo (2026-10-09), every file outlined vector paths with no font dependency.

- `eta-lockup-horizontal.svg`: primary lockup, full color for light grounds (faces #6aa5f7, #1d73ed, #0f3c87; type #14151a).
- `eta-lockup-horizontal-reversed.svg`: for band-dark and dark photos (faces #b7d4fb, #6aa5f7, #1d73ed; type #f4f4f2).
- `eta-lockup-horizontal-mono-ink.svg`: one color, #14151a.
- `eta-lockup-stacked.svg`, `eta-lockup-stacked-reversed.svg`: centered and square spaces.
- `eta-wordmark.svg`: ETA with the descriptor, no mark, for running footers.
- `eta-mark.svg`, `eta-mark-reversed.svg`: the mark alone, full color.
- `eta-mark-mono-ink.svg` (#14151a) and `eta-mark-mono-white.svg` (#ffffff): one-color marks.
- `eta-mark-ceremonial-gold.svg`: gold faces (#f6d27a, #eeb32b, #a8761a) for band-dark only, never beside blue.
- `eta-app-icon.svg`, `eta-app-icon-512.png`: reversed mark on a #14151a rounded square (22% corner radius) for app icons, favicons and avatars.

Clear space is one third of the mark's height on every side. Minimum widths: horizontal lockup 160px, stacked 72px, mark 16px.
