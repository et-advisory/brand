# Eyebrow

Eyebrow is the small uppercase label that sits above a heading and names the section.

**The consumer provides** one to four words. Render it as `<ETA.Eyebrow>Capital formation</ETA.Eyebrow>`; `size="slide"` gives the 24px slide label.

**When to use.** Above every SectionHeading and slide title. It is 12px, weight 600, tracking 0.18em, set in `accent-strong`.

**Do**
- Use the 12px size; the token's 11px note is superseded by what the component and specimens ship.
- On a slide, use `size="slide"` (24px, the `slide-label` size) with the same tracking.

**Do not**
- Do not write a sentence or add a period.
- Do not color it with `gold` or a letter color.
